# doc_old —— V2 文档存档（只读）

这些是 `PitchMorph-V2` 仓库 `docs/` 的原样副本，搬过来是为了「需要追溯时不必切仓库」。
**它们记录的是 V2 的实现与当时结论，不是 V3 的设计。**

## 与 `docs/` 的分工

| 目录 | 性质 | 什么时候看 |
|---|---|---|
| `docs/` | V3 自用，随实现更新 | 日常开发 |
| `doc_old/` | V2 存档，**不再修改** | 追溯某个结论的来源、核对 V2 的实现细节（算法参数、边界条件、踩过的坑） |
